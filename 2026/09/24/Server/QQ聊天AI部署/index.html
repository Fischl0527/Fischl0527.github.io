QQ聊天AI部署（未完待续）

发表于2026-09-24|更新于2026-09-24|Notes
|总字数:2.3k|阅读时长:8分钟|浏览量:

本文章主要是说明了如何在 QQ 聊天群里部署一个有特色的聊天 AI 的步骤，大致流程如下：QQ → NapCat → OneBot v11 反向 WebSocket → AstrBot → DeepSeek API → AstrBot → NapCat → QQ。其中 NapCat 负责 QQ 消息收发，AstrBot 负责会话管理、人格、插件与模型调用，DeepSeek 负责生成 AI 回复。

安装 Docker 并部署 NapCat + AstrBot

登录自己的服务器，我用的是阿里云服务器（阿里云服务器的购买与搭建看我另一篇文章），Ubuntu 仓库简易安装下载 docker

然后创建目录，下载 NapCat 官方提供的 AstrBot Compose，官方目前的 Compose 会同时启动 napcat 和 astrbot。

astrbot.yml 的配置如下：

这个配置是 NapCat 官方的当前 Compose 默认把6099暴露到宿主机，AstrBot 默认也映射 6185，由于我的是在服务器上面的，根据 AI 的安全策略，我通过 SSH 隧道管理改成监听127.0.0.1，这样 NapCat WebUI 与 AstrBot Dashboard 就不直接监听公网地址，只绑定 127.0.0.1，后续通过 SSH 端口转发访问这几个 WebGUI 了。因此阿里云安全组无需开放 6099、6185、6199，在云服务器上反而是更安全的。
